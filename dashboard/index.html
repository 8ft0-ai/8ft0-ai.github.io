Research landscape / October 2026

Which research claims are worth testing?

Four directions emerge from the papers selected for closer reading: queue-aware impact, communication-driven herding, round-number liquidity and strategy-code equivalence. These are editorial priorities within incomplete selections, not measured research trends or independently replicated results.

01 / Research questions worth challenging

Findings first, tests next

Each result below is author-reported; the proposed test is Quant Radar's interpretation, not a completed experiment.

Does queue state explain price impact beyond aggressive trades?

Finding: For E-mini S&P 500 futures in 2025, the authors report mean daily out-of-sample price-change R² of 0.458 for a classical propagator versus 0.603 with the full queue-state dictionary.

Test: Match model complexity and held-out order-book periods, then evaluate the price-fit lift in stressed sessions. Prioritise an execution study only if fills and adverse selection also improve.

Source, method and limitations ↗

Is agent herding caused by communication or common inputs?

Finding: Across 200 simulated managers over seven US trading days, the authors report 7 percentage points more phrase reuse after groupmate messages but no detected immediate trading shift; isolated managers also converged.

Test: Match model family and inputs in communicating versus no-peer groups. Demote the communication hypothesis if excess holdings overlap disappears after the common-input baseline.

Source, comparator and limitations ↗

Does round-number depth produce a genuine price barrier?

Finding: Across five Nasdaq stocks, displayed depth increased near round dollars; Intel and SoFi instead had shorter adjusted price-level residence, with reported duration indices around 0.93–0.94.

Test: Compare matched entry-depth duration hazards and departure direction against ordinary and placebo levels on held-out days. Greater depth alone must not count as barrier evidence.

Source, depth controls and limitations ↗

Can strategy code run while violating its stated instructions?

Finding: In MintEval's reported stratified 200-task model subset, exact reproduction reached 57.5%. Runnable code and a plausible return series did not establish bar-by-bar strategy equivalence.

Test: Replay frozen reference and generated programs on identical bars, costs and risk states. Failure is a mismatched action or stop/cooldown transition, even when aggregate P&L looks acceptable.

02 / Counterevidence and decision changes

What would change priorities?

Negative comparisons and changed measurement clocks can matter more than another optimistic model score.

Adaptive quotes did not beat the fixed two-tick wealth baseline

In a five-day MSFT simulation, the authors report US$3,165,081 adaptive terminal wealth versus US$3,443,368 for fixed two-tick quoting. This does not rank the inventory-penalised objective.

Priority switch: Reconsider adaptive quoting if a matched pre-liquidation inventory-penalised comparison improves payoff without worse inventory excursions.

Read the comparative evidence ↗

A better label clock can change the claimed prediction target

In the authors' 552-call earnings sample, moving from documentary call start to an audio-completion proxy reverses the return sign for 9.4% of calls. The proxy is not verified live transcript availability.

Priority switch: Audit available-at and decision-at timestamps before pursuing benchmark improvements; otherwise a backtest can use information before it existed.
